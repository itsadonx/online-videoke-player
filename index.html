          OVP

          Online Videoke Player

          Created by: Adonnis Pama

          Add multiple keys. When one hits its daily quota, OVP tries the next automatically. Keys are saved in this browser only — add them on the TV or PC running the player (phone remotes use the player’s keys, not the phone’s).

            Enable YouTube Data API v3 in Google Cloud. Restrict each key by HTTP referrer (e.g. https://your-app.onrender.com/*). Stored in this browser only.

            Google Drive videos

            Upload karaoke videos to a Google Drive folder. Share the folder (and each video) as Anyone with the link → Viewer. Enable Google Drive API in the same Google Cloud project as your YouTube API key.
